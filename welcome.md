# Welcome to MarkLex

**MarkLex - Marketing Lexicon Creation**

We present **MarkLex**, an innovative web application that serves a dual purpose:

## Key Features

**1. Custom Lexicon Creation** (Primary Feature)

MarkLex integrates two domain-trained word embeddings models. Enter a seed word, and the model will produce a ranked list of semantically similar words. This empowers users to build lexicons beyond predefined categories effortlessly.

Our models were trained using text from **13,312 unique firms'** SEC EDGAR filings over **23 years**, corresponding to about **543,747,600 sentences**, making the textual corpus exhaustive and diverse.

**2. Predefined Lexicon Analysis** (Secondary Feature)

MarkLex offers a predefined lexicon for analyzing eight major marketing constructs:
- **Marketing** - Customer satisfaction, branding, product/service, advertising, promotion
- **Environmental, Social, and corporate Governance (ESG)**
- **Risk and Security** 
- **Diversity, Equity, and Inclusion (DEI)**
- **Employee Relations**
- **Artificial Intelligence (AI) and Data**
- **Innovation**
- **Investor Focus**

**Validation Results**: 94% accuracy rate and 89% F1 score.

## How to Use

- **Lexicon Tab**: Create custom word lists from seed words
- **Text Analysis Tab**: Analyze text using predefined business dimensions  
- **Export**: Download results as CSV files for further analysis

---

*The F1 score ranges from 0 to 1, where 1 indicates perfect precision and recall. It is particularly useful when there is class imbalance, as it considers both false positives and false negatives.*
